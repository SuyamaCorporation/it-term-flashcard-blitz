## ITエンジニア用語フラッシュカード・ブリッツ

ネットワーク・DB・インフラ・セキュリティ・アーキテクチャ5分野60語をフラッシュカードで学習できる、採用試験対策ツール。

### 機能
- 60語の技術用語カードを内蔵（5カテゴリ×12語）
- カテゴリ別・難易度別（ジュニア/ミドル/シニア）フィルター
- CSS 3Dフリップアニメーション付きカード表示
- 自己評価（知ってた/曖昧/知らなかった）で学習記録
- 30秒タイムアタック「ブリッツモード」
- ブックマーク機能・苦手用語のみ復習
- localStorage による学習進捗・ブックマーク・ブリッツ記録保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- CSS transform: rotateY によるカードフリップ
- localStorage 永続化
